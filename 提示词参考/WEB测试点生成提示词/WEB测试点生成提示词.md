# 测试点生成规范（统一内部模板，无需用户额外提供）
## 单功能模块文件（功能名.md）内部固定结构
1. 模块基础信息：对应原需求文档编号、功能简述、关联需求原文摘抄
2. 功能流程测试点：按用户操作时序拆分正向、逆向流程测试点
3. 字段校验测试点：输入框、下拉、单选、上传、日期等所有页面字段长度、格式、为空、边界值
4. 交互校验测试点：弹窗提示、按钮置灰、权限拦截、页面跳转、刷新回显
5. 异常场景测试点：网络异常、重复提交、超时、非法参数
备注：所有测试点简洁直白，一条测试点对应一个校验动作，不合并多条逻辑

## 全局通用模块文件（00_全局通用模块.md）内部固定结构
1. 公共功能清单：罗列所有复用公共功能、复用模块数量、覆盖功能名称
2. 通用页面交互测试点：页面返回、浏览器刷新、返回上一页、退出登录、密码通用校验
3. 通用弹窗/提示测试点：系统报错、操作成功、权限不足全局提示
4. 通用权限测试点：游客/普通用户/管理员通用权限拦截逻辑
