# API 接口文档生成规范

本文档定义 `api-doc-generator` 的生成规则。最终 Markdown 文件结构见 `apidoc-template.md`。

## 事实性约束
- 只记录 raw JSON 中真实存在的数据，禁止臆测业务规则、异常响应、示例值或参数说明。
- 正常响应必须来自 `response.body`；未捕获时标注“未捕获到响应体”，不得伪造 JSON。
- 异常响应必须来自真实 HTTP 4xx/5xx 或业务错误码；没有异常响应时，5.2 章节写“录制批次中未捕获到异常响应，请补充”。
- 用户主动补充的信息可以写入文档，但应保留用户原话，不擅自扩写。

## 输入规则
- 默认读取 `{项目目录}/AI-接口采集/{批次号}/raw*.json`。
- 指定批次后，遍历 raw JSON 数组中的全部 request/response，不能只取第一条。
- 所有 JSON 和 Markdown 按 UTF-8 读写。

## 解析规则
- `method` 来自 `request.method`，输出时统一大写。
- `path` 来自 `request.url` 去掉域名和 query 后的路径。
- `query_keys` 来自 URL query 参数名，按字母序排列。
- 请求头只保留必要字段：`Content-Type`、`Authorization`；浏览器自动头默认不写入文档。
- 请求体示例直接来自 `request.body`，缺失则写统一占位。
- 响应示例直接来自 `response.body` 原始字符串，不重新构造。

## 名称推导规则（中英文双名）
- 接口名同时保存中文与英文两部分，便于检索和阅读。
- **本技能不内置**任何 `path → 中文名` 规则表（避免脚本"帮用户脑补"业务名）。
- 名称**完全由 AI 注入**——必须通过 `--module-assignments` JSON 的 `zh` / `en` / `desc` 字段传入：
  - **必传**：`zh`（中文名）、`module`（所属模块）
  - **建议传**：`en`（英文名，建议与 path 末段保持一致便于检索）、`desc`（业务描述，**禁止写"待补充"**）
- MD 文档”一、基本信息 → 接口名称”展示同样的双名格式。
- 文件名格式与 `name` 字段一致：`{中文}_{英文}.md`（下划线连接）。


## 去重规则
- `path` 与 `method` 相同的接口，按字母序排列。


## 输出规则

- 输出目录：`{项目目录}/{模块名}/`。
- 文件名（中英文双名）：`{中文}_{英文}.md`，示例：
  - `登录_login.md`
  - `刷新Token_refreshToken.md`
  - `点击榜_listClickRank.md`
- 同名冲突降级：`{中文}_{英文}__{METHOD}.md` → `{中文}_{英文}__{METHOD}__{path末段}.md`。
- 非法字符：`< > : “ / \ | ? *` 自动替换为 `_`，避免 Windows 文件名规则冲突。
- 每个接口必须有一个 32 位小写无横杠 UUID：`uuid.uuid4().hex`。
- 文档必须完整包含“一、基本信息”到“五、响应”，其中 5.1 和 5.2 小节必须齐备。
- raw 中缺失内容时：
  - 表格单元格写 `待补充`。
  - 代码块内写 `// 待补充：请提供真实数据`。
  - 章节顶部可写 `⚠️ 录制批次中未捕获到 XX 数据，请补充`。

## 完成报告

完成后用中文输出：

```text
已生成接口文档。
批次号：{批次号}
扫描条目：{total_entries} 条 → 去重后 {total_unique} 个接口
索引匹配：新增 {new_count} 个 / 跳过 {existing_skipped} 个 / 覆盖更新 {existing_overwritten} 个

新增文档：
1. {模块名}/{中文}_{英文}.md ← {METHOD} {path}

跳过文档（已存在，按用户默认行为不覆盖）：
1. {模块名}/{file} ← {METHOD} {path}

覆盖更新（用户明确说明更新已有时才有）：
1. {模块名}/{中文}_{英文}.md（先删旧文件 {old_file}，再按新规则生成） ← {METHOD} {path}

索引文件：
- {项目目录}/接口_index.json

验证：
- 仅读取指定批次：{批次号}
- 正常响应体非空接口：{with_body} 个 / 无响应体：{no_body} 个
- 异常响应捕获：{has_error_responses} 个接口有异常响应 / {no_error_responses} 个接口无异常响应
- 未编造响应、示例值或参数说明
- 所有 name 字段为「中文_英文」下划线格式（如 登录_login）
- 覆盖模式：先删旧 MD 再按新规则生成新文件
```
