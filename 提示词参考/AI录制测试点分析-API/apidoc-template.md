# API 接口文档 Markdown 模板

本文档只定义 `api-doc-generator` 最终输出的单接口 Markdown 文件结构。生成策略、事实性约束、批次选择、索引回写规则见 `apidoc-spec.md`。

## 文件命名

`{中文}_{英文}.md`（下划线连接）

示例：
- `登录_login.md`
- `刷新Token_refreshToken.md`
- `点击榜_listClickRank.md`

> **冲突降级**：同名时 → `{中文}_{英文}__{METHOD}.md` → `{中文}_{英文}__{METHOD}__{path末段}.md`。
>
> **非法字符**：`< > : " / \ | ? *` 自动替换为 `_`。
>
> **覆盖模式**：先删除旧 MD（按索引中 `file` 字段定位），再按新规则生成新文件。

## 填写规则

- 模板中的 `{...}` 必须替换为真实内容或统一占位文本，不保留花括号占位。
- raw 中缺失的信息统一写 `待补充`，代码块内写 `// 待补充：请提供真实数据`。
- 不删除章节；没有数据也保留章节并明确标注未捕获。
- 每个接口独立一个 Markdown 文件。
