# 勾股5.0 软件需求规格说明书——登录模块

## 1. 引言

### 1.1 目的
本文档旨在详细描述勾股5.0登录模块的功能需求、非功能需求、外部接口及验收标准，为开发、测试和项目验收提供统一依据。

### 1.2 范围

### 1.3 定义、缩略语
- **JWT**：JSON Web Token，用于生成会话令牌。

## 2. 总体描述

### 2.1 产品背景
勾股5.0是一款面向企业用户的数智化协同管理平台，致力于提供高效、智能、易扩展的解决方案。登录模块作为系统入口，需保证安全性与流畅体验，支撑企业员工通过统一认证访问内部工作台。

### 2.2 产品功能
- 提供账户/手机号 + 密码 + 验证码的多因素认证。
- 支持登录过程中的前端校验、后端认证、令牌生成及会话管理。
- 提供验证码获取与校验机制。

### 2.3 用户特征
| 角色 | 说明 |
|------|------|
| 企业员工 | 已开通系统账号，需登录使用各类协同功能 |
| 系统管理员 | 负责账号管理及安全策略配置 |

### 2.4 约束条件
- 本次发布不包含“记住密码”或“忘记密码”功能。
- 默认强制使用验证码；如企业要求简化登录，需通过后端配置开关实现。
- 令牌有效时长：8小时（可配置）。

### 2.5 假设与依赖
- 用户已开通勾股5.0账号。
- 后端提供账户校验、验证码生成及校验、令牌颁发能力。

## 3. 外部接口需求

### 3.1 用户界面
登录页面自上而下包含：
- 标语区：“企业数智化 协同·高效·智能·易扩展 勾股5.0”
- 账户/手机号输入框（占位提示“请输入账户或手机号码”）
- 密码输入框（占位提示“请输入密码”，点状掩码）
- 验证码行：验证码输入框（占位提示“验证码”）+ 获取验证码按钮（显示加法运算）
- 登入系统按钮

界面需适配移动端H5，输入框自动获取焦点。

### 3.2 硬件接口
无特殊硬件要求。

### 3.3 软件接口
| 接口名称 | 说明 |
|----------|------|
| 登录认证接口 | 接收账户/手机号、密码、验证码，返回令牌或错误信息 |
| 获取验证码接口 | 生成加法验证码并返回给前端，后端存储结果 |

### 3.4 通信接口
- 协议：HTTPS
- 数据格式：JSON
- 密码传输需使用RSA/AES前端加密。

## 4. 功能需求

### 4.1 登录认证模块

![image-20260603203834518](P01-%E7%99%BB%E5%BD%95%E5%8A%9F%E8%83%BD%E9%9C%80%E6%B1%82%E6%96%87%E6%A1%A3.assets/image-20260603203834518.png)

#### 4.1.1 功能描述
用户通过账户/手机号、密码、验证码完成身份认证，获得访问令牌。

#### 4.1.2 输入/输出
- **输入**：账户/手机号（字符串）、密码（字符串）、验证码（数字）
- **输出**：成功时返回JWT令牌及用户基本信息；失败时返回错误码及提示信息。

#### 4.1.3 业务规则
- 账户/手机号：非空；支持手机号（11位数字，1开头）或账户名（4~20位字母/数字）
- 密码：非空；长度6~20位；至少包含字母和数字
- 验证码：输入必须等于后端生成的加法运算结果
- 连续5次密码错误，账号锁定15分钟
- 验证码输入错误超过3次，需重新获取验证码

## 5. 性能需求

### 5.1 性能指标
| 指标 | 要求 |
|------|------|
| 登录接口响应时间 | ≤ 300ms（95%请求） |
| 验证码发送接口响应时间 | ≤ 500ms |

### 5.2 可靠性要求
- 系统应支持7×24小时运行。
- 单次登录失败不应导致服务不可用。

### 5.3 可用性要求
- 支持移动端H5适配，输入框自动获取焦点。
- 倒计时期间按钮清晰显示剩余秒数。

---

## 6. 约束条件

### 6.1 法规约束
- 用户密码及验证码不得记录在前端日志。
- 需符合企业数据安全合规要求。

### 6.2 硬件限制
无特定硬件限制。

### 6.3 技术限制
- 前端兼容Chrome 80+、Firefox 75+、Safari 13+、Edge 80+；移动端iOS 12+、Android 8+。
- 后端需提供防暴力破解机制。
